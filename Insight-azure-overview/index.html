What is CTERA Insight?

An AI-Driven Analytics Service for the CTERA Intelligent Data Platform

  • Centralized File System Analytics: Unified view of storage capacity trends, file distribution, and folder growth across your entire CTERA deployment.
  • Granular User Activity Auditing: Monitor all SMB operations with analysis by user, filer, or portal — essential for security forensics.
  • AI-Powered Conversational Query: An agentic AI assistant lets administrators query metadata using natural language for immediate answers.
  • Secure Multi-Tenant Architecture: Full data isolation at the index, namespace, and access control levels.

Architecture Overview

A two-environment architecture separating platform management from customer data processing, connected via secure private link.

Applications & Security

Identity

CTERA Portal is the source of user identity — users authenticate via existing Portal credentials. Scoped access tokens enforce per-tenant data isolation.

Security Boundaries

  • Private networking — all components in private subnets
  • Encryption — at rest (Key Vault) and in transit (TLS 1.2+)
  • Tenant isolation — namespace, index, and ACL level
  • No standing data access — infra only, not data

Deployment Options

Two models to accommodate different security, compliance, and operational requirements.

SaaS: CTERA provisions and operates all infrastructure in CTERA's own Azure tenant. Zero customer operations.
BYOC: Customer provides a dedicated Azure subscription. CTERA deploys and operates within it. All data stays in the customer environment.
