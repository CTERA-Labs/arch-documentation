Cost Model Overview

This calculator estimates the customer's cloud infrastructure cost for a CTERA Insight BYOC deployment - a single workload cluster running a single tenant in the customer's AWS or Azure subscription.

What's Modeled

  • Workload cluster: Kubernetes control plane, OpenSearch (3 master + N data nodes), application nodes (Atlantis, Backoffice, ArgoCD, Argo Workflows, insight-ui, agent-service, self-hosted Git, self-hosted artifact registry), Ingestor JobManagers (always-on) and processing nodes (scale-to-zero, hourly runs).
  • Storage: EBS gp3 / Premium SSD v2 for OpenSearch data nodes (sized from retention), application-node PVCs for Git + artifact repo, S3 / Blob Hot for input bucket and ingestor checkpoints.
  • Network: Internal load balancers, NAT Gateway, cross-AZ OpenSearch replication (when 3-AZ enabled), egress, DNS.
  • Managed services: Secrets Manager / Key Vault, KMS / Key Vault keys, CloudWatch / Log Analytics.

Key Sizing Formulas

  • Ingestor processing nodes = max(min, ceil(state_GB / (NVMe × 85%))), where state_GB = files × 0.5 KB.
  • OpenSearch storage = (fs_md + audit_rollup + folder_snapshots) × (1 + replicas) × 1.3 indexing overhead, divided across data nodes.
  • Audit log volume = files × 0.012 rollup rows/day. Only rolled-up records are stored; raw events are out of scope for OS sizing.
  • Folder snapshots = (files × 2%) × 1 KB/day × retention.
  • Cross-AZ replication applies only in 3-AZ deployments and is calculated from daily ingest volume × replicas.

Out of Scope

  • LLM token costs for the agent service (customer-supplied API key, usage-based).
  • Initial sync ("INIT phase") burst capacity. The model estimates steady-state BAU costs.
  • Customer-side network costs outside the cluster (corporate egress to the platform, etc.).

Pricing

All rates are on-demand list prices as published by AWS us-east-1 and Azure East US at the time the calculator was built. Customers should apply their contracted, Reserved Instance, or Savings Plan discounts to the exported BoM.
